# security

* **KMS CMKs, one per data domain:** `rds`, `elasticache`, `secrets`, `messaging` (SQS and SNS), `s3`, `logs`,
  `ecr`. Each has annual automatic rotation, is single-region and uses the alias `alias/<name>-<domain>`. Key
  policies delegate to IAM through the account root. The `logs` key adds the CloudWatch Logs service principal
  (scoped by encryption context), and the `messaging` key allows CloudWatch alarms to publish to the encrypted SNS
  topic.
* **WAFv2 regional web ACL:** the AWS managed groups IP reputation, Common, KnownBadInputs (Log4j) and SQLi, plus
  two per-IP rate rules: `/v1/(platform/)?auth/*` plus `/v1/institutions/*/customers/register` (default 100 per
  5 min) and global (default 2000 per 5 min). When `platform_admin_cidrs` is set, `/v1/platform/*` is blocked
  from any source outside that IPv4 IP set.
  Logs go to `aws-waf-logs-<name>` with the `authorization` and `cookie` headers redacted.
* **App secret** `<name>/app` holds the JSON keys `jwt_secret`, `bvn_hmac_key` and `data_encryption_key`
  (base64 of 32 random bytes, for AES-256-GCM), all generated by Terraform.

Output `kms_key_arns` is a map of domain to ARN.
